# Moto MR

Sistema de punto de venta (POS) para una tienda de repuestos de moto: inventario, clientes, usuarios y facturación.

## Estructura
- `frontend/`  → HTML, CSS y JS (login, inicio, venta, productos, clientes, usuarios)
- `backend/`   → PHP (API), pendiente
- `database/`  → scripts MySQL (`moto_mr_1.sql`)
- `docs/`      → documentación técnica y notas

## Estado
- Front-end: hecho, con datos de ejemplo guardados en el navegador
- Base de datos: script inicial (v1), pendiente de ajustes
- Backend PHP: pendiente

## Probar el front-end
Abrir `frontend/login.html`. Datos de prueba: `admin@motomr.co` / `1234`
